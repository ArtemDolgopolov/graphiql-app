# Graphql app

## About

GraphQL is an open-source query language for APIs and a runtime for executing those queries. GraphQL provides declarative data fetching, allowing the client to specify exactly what data it needs from the API.

## Technologies Used

- HTML5
- CSS3
- TypeScript
- React
- Redux
- Redux Toolkit
- RTK Query
- React Router
